# Academic GitHub Pages Template

This is a no-build static website template for GitHub Pages.

## Files

- `index.html` — homepage
- `publications.html`
- `projects.html`
- `service.html`
- `teaching.html`
- `students.html`
- `styles.css` — shared styling
- `script.js` — shared theme toggle, mobile navigation, and publication filtering

## How to use

1. Replace `Your Name`, `Your University`, `your.email@university.edu`, and placeholder content across the HTML files.
2. Add your actual CV link, Google Scholar, ORCID, LinkedIn, and paper links.
3. Push the files to a GitHub repository.
4. In GitHub, open **Settings → Pages**.
5. Set the source to **Deploy from a branch** and choose the branch containing these files.
6. Save. GitHub Pages will publish the site automatically.

## Recommended customisations

- Add a profile photo by replacing the `YN` avatar block on `index.html` with an `<img>` tag.
- Add a `CNAME` file if you want to use a custom domain.
- Add folders such as `assets/` for photos, PDFs, or other files.

## Notes

- The template includes light and dark modes.
- The homepage is intentionally minimal.
- Richer content is moved to dedicated subpages to keep the landing page clean and professional.
